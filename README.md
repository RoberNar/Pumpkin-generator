# Pumpkin-generator

Generador procedural de calabazas para Axiom. Permite generar calabazas con diferentes tamaños, formas y opciones de detalle, exportando el script directamente a Lua para utilizarlo en el juego.

## Despliegue en Railway

Este repositorio está preparado para ser desplegado en [Railway](https://railway.app/). Utiliza `serve` para alojar los archivos estáticos.
